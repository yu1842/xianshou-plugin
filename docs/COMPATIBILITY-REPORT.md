## 4. 降级行为矩阵

| 缺失的接缝 | 影响的功能 | 替代路径 | 用户可见变化 |
| --- | --- | --- | --- |
| `ctx.tools.guard` | 单调守卫 | 仅保留 `pre-execute` 拦截 | `deny` 模式仍拦截，但不再防"监听器重排" |
| `tools/pre-execute` | 先手闸门 | 无（闸门整体跳过） | 卡片正常、记录正常，但不再拦截写入 |
| 会话状态读写 | 会话级持久化 | 文件仓储（`<cwd>/.xianshou/tasks`） | 换 profile 时任务不跟随 |
| `ctx.emit` | 会话事件投影 | 仅日志 | 界面收不到提醒事件，日志仍可追溯 |
| `ctx.effect` | 会话内定时扫描 | 启动补扫 | 长会话中不会主动弹提醒，重启后补推 |
| 全部缺失（最小宿主） | 只剩工具与渲染 | —— | 工具可调用，闸门与提醒均降级 |
